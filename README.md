# West Side Grill Website

Official website for West Side Grill.

## Production
- Website: https://westsidegrill.biz
- Repository: https://github.com/Gofke/Westgrill

## Technology
- HTML
- CSS
- JavaScript
- Static image assets
- Nginx / CloudPanel deployment

## Branches
- main = production
- develop = testing/integration
- feature/* = new features
- fix/* = bug fixes
- hotfix/* = urgent production fixes

## Commit Convention
- feat: new feature
- fix: bug fix
- content: content changes
- style: visual/style changes
- assets: image/asset changes
- docs: documentation
- chore: maintenance

## Release Tags
Production releases use version tags such as:
- v1.0.0
- v1.0.1
- v1.1.0
